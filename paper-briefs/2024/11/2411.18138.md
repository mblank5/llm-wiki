# SALMONN-omni：一种无编解码器的全双工语音理解与生成模型

## 一句话定位

提出首个无编解码器的全双工语音理解与生成模型 SALMONN-omni，通过嵌入级联和“思考”机制实现实时双向语音交互，支持语音识别、增强、问答及动态对话管理。

## 为什么值得记录

- 首次实现无编解码器的全双工端到端语音 LLM，避免传统模块化系统的误差累积问题
- 引入“思考”机制与状态切换 token，有效处理自然对话中的抢话、回声消除和话轮转换
- 统一框架支持多种流式语音任务（识别、增强、问答等），具备强泛化能力
- 为下一代自然、低延迟人机语音交互系统提供可复现的技术原型

## 核心方法

- 采用端到端架构，集成流式语音编码器、LLM 和流式语音合成器，全部通过嵌入向量连接，不使用任何离散语音 token（codec-free）
- 设计周期性同步机制，在每个时间块内处理固定时长输入语音并生成固定数量文本嵌入，确保视听模态对齐
- 引入 <start_speak> 和 <end_speak> 两个特殊 token 控制说话/非说话状态切换，实现全双工交互
- 提出“思考”机制：在状态切换间隙使用 <think> token 作为输入占位符，输出标签设为下一状态触发 token，并通过负权重损失项（λ_think < 0）引导模型学习内部推理过程
- 训练目标包含三部分损失：文本生成损失 L_text、语音生成损失 L_speech 和思考损失 L_think，总损失为加权和

## 关键结果

- 在多种流式语音任务上验证有效性，包括语音识别、语音增强、去混响、目标说话人提取和口语问答
- 在模拟实验中成功处理上下文无关和上下文相关的抢话（barge-in）场景，能根据用户输入决定是否中断当前语音输出
- 具备回声消除能力：在播放自身语音的同时仍能准确检测用户指令（如“Yes”）并响应
- 支持自然话轮转换，在口语问答中实现流畅的人机对话交互
